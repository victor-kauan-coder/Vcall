**Vcall 3.7.1**: trocar de câmera volta a funcionar, e o aviso "Carregando o vídeo…" não fica mais preso no seu quadro.

## 📷 Trocar de câmera

- **Escolher outra câmera não mudava nada.** O app pedia a câmera escolhida como *preferência*, e o sistema ficava com a que melhor atendia à resolução, quase sempre a mesma. Num Windows com o celular ligado como câmera, era sempre a do celular. Agora a câmera que você escolhe é a que abre, e o mesmo vale para o microfone.
- Se a câmera salva não existe mais (foi desconectada, por exemplo), o app abre a câmera padrão do sistema em vez de ficar sem vídeo.

## ⏳ "Carregando o vídeo…"

- O aviso aparecia **o tempo todo**, cortado ao lado do seu vídeo, mesmo com a câmera funcionando. Uma chave faltando no CSS fazia o app ignorar o fim da folha de estilos.
- Com o CSS de volta, também passam a aparecer como foram feitos o quadro "você está apresentando", o balão flutuante da chamada a dois, a sala de espera, o painel de transcrição, o medidor de sensibilidade do microfone e as faixas para arrastar a janela.
- A verificação do projeto passa a recusar CSS com chave sem par, para isso não voltar.

> **Imagem preta mesmo depois de trocar?** A câmera está mandando imagem preta. Abra a tampa de privacidade da câmera ou aperte a tecla de câmera do notebook (a que tem o desenho de câmera riscada). Se for a câmera do celular, confira se ele está conectado em *Configurações do Windows › Bluetooth e dispositivos › Dispositivos móveis*.

## 🔄 Atualização

Quem está na **3.7.0** no Windows ou no AppImage recebe esta versão sozinho. No `.deb` e no `.rpm`, clique em *Configurações › Atualizações › Reiniciar e atualizar*.

## ⬇️ Qual arquivo baixar

| Sistema | Arquivo | Como instalar |
| --- | --- | --- |
| **Windows 10/11** | `VcallSetup-3.7.1.exe` | Execute (feche o Vcall antes). No aviso do SmartScreen: *Mais informações → Executar assim mesmo* |
| **Ubuntu, Debian, Mint, Pop!_OS** | `Vcall-3.7.1-amd64.deb` | `sudo apt install ./Vcall-3.7.1-amd64.deb` |
| **Fedora, openSUSE, RHEL** | `Vcall-3.7.1-x86_64.rpm` | `sudo dnf install ./Vcall-3.7.1-x86_64.rpm` |
| **Arch, Manjaro, EndeavourOS** | `Vcall-3.7.1-x64.pacman` | `sudo pacman -U ./Vcall-3.7.1-x64.pacman` |
| **Qualquer Linux** | `Vcall-3.7.1-x86_64.AppImage` / `.tar.gz` | `chmod +x` e execute / descompacte e rode `./vcall` |
