**Vcall 3.15.2**: no Linux, compartilhar a tela agora pode levar o som do computador.

## Som do computador no Linux

No aplicativo de mesa, a opção **Compartilhar o som do computador** só aparecia no Windows. Agora ela aparece também no Linux (X11 e Wayland). Ligada, a tela vai junto com o som que sai pelos alto-falantes, capturado do monitor de som do PulseAudio ou do PipeWire.

Como no Windows, esse som inclui as vozes da própria chamada: use fones para os outros não se ouvirem de volta. Se o sistema não tiver um monitor de som, a tela vai sem som e o Vcall avisa.
