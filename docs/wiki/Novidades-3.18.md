# Novidades da 3.18

## 3.18.0: sala grande sem travar a tela

- **Transmitir para 3 ou mais pessoas:** o aplicativo de mesa codifica a
  tela uma vez só. Um servidor de mídia (LiveKit) dentro do próprio app
  repassa a imagem para cada pessoa. Com 5 assistindo, a tela foi de 634×344
  a ~30 quadros por segundo para 1404×760 a ~59.
- **Cifrado de ponta a ponta:** o servidor repassa a imagem sem conseguir
  vê-la. A chave muda a cada transmissão e só anda de pessoa para pessoa.
- **Sem configurar nada:** quem assiste entra pelo mesmo link da sala. Se a
  conexão com o seu PC não fechar, essa pessoa continua recebendo direto,
  como antes.
- **Sala de 2 e navegador:** nada muda.

Mais detalhes em [Compartilhar a tela](Compartilhar-a-tela).
