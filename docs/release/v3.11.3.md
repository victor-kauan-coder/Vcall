**Vcall 3.11.3**: o convite no WhatsApp aparece só como cartão, sem o endereço escrito.

## Convite só com o cartão

**Enviar pelo WhatsApp** agora manda só o link, sem a frase "Entra na minha chamada...". Mensagem que é só um link o WhatsApp mostra só como cartão: a imagem da marca, o nome da chamada, "Toque para entrar" e o domínio embaixo, como um Reels do Instagram. O nome da chamada continua no cartão.

> Se você escrever algo junto do link, o WhatsApp volta a mostrar o endereço inteiro. Mande o texto numa mensagem separada.
