**Vcall 3.11.2**: tocar no convite pelo celular abre a chamada direto no aplicativo.

## O convite abre o app no Android

Antes, tocar no link do convite no celular abria a chamada no navegador, mesmo com o app Vcall instalado. Agora:

- **Android com o app Vcall:** a chamada abre direto no aplicativo, sem perguntar.
- **Android sem o app:** o navegador segue para a chamada, como antes.
- **iPhone:** a chamada no navegador (não há app para iPhone).

Vale para o link curto (`/c/ABC123`) e para o `/abrir#` antigo. Se o app não abrir por algum motivo, a página continua com os botões **Abrir no aplicativo Vcall** e **Entrar pelo navegador**.

> Um link `http://` de rede local continua no navegador: o app só entra em chamada com criptografia (HTTPS).
