**Vcall 3.1.1** — correção do visualizador de imagens no aplicativo de mesa.

## 🛠️ Correção

- **Não dava para sair da prévia de uma imagem.** No aplicativo, o topo da janela tem os botões do Windows (minimizar, maximizar, fechar) desenhados por cima da página e uma faixa de arrastar a janela. A barra do visualizador — com o **X** e o **Baixar** — ficava justamente ali: o X ficava embaixo do botão de fechar do Windows e clicar nele só arrastava a janela. Agora a barra fica abaixo dos botões da janela, fora da faixa de arrastar, e o X fecha normalmente (o `Esc` e o clique fora da imagem também).

Tudo o que veio na [3.1.0](https://github.com/victor-kauan-coder/Vcall/releases/tag/v3.1.0) continua valendo.

## ⬇️ Qual arquivo baixar

| Sistema | Arquivo | Como instalar |
| --- | --- | --- |
| **Windows 10/11** | `VcallSetup-3.1.1.exe` | Execute (feche o Vcall antes). No aviso do SmartScreen: *Mais informações → Executar assim mesmo* |
| **Fedora, openSUSE, RHEL** | `Vcall-3.1.1-x86_64.rpm` | `sudo dnf install ./Vcall-3.1.1-x86_64.rpm` |
| **Arch, Manjaro, EndeavourOS** | `Vcall-3.1.1-x64.pacman` | `sudo pacman -U ./Vcall-3.1.1-x64.pacman` |
| **Ubuntu, Debian, Mint, Pop!_OS** | `Vcall-3.1.1-amd64.deb` | `sudo apt install ./Vcall-3.1.1-amd64.deb` |
| **Qualquer Linux** | `Vcall-3.1.1-x86_64.AppImage` / `.tar.gz` | `chmod +x` e execute / descompacte e rode `./vcall` |
