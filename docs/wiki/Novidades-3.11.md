# Novidades da 3.11

## O AppImage abre no Wayland

No Fedora, no Ubuntu com GNOME e no KDE, o AppImage aberto pelo menu não
subia ("Cannot mount AppImage"). Corrigido: o app passa para o XWayland sem
sair do processo. → [Solução de problemas](Solucao-de-problemas#o-appimage-não-abre)
