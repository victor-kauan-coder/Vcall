# Novidades da 3.19

## 3.19.0: as US do GitHub na mesa do Planning Poker

- **Do quadro para a mesa:** o botão **GitHub** traz as US de uma coluna de
  um GitHub Project. Você escolhe o projeto na lista e marca as US que vão
  para a votação.
- **A US inteira à vista:** a história em votação mostra as subtarefas
  (sub-issues), os critérios de aceite (a checklist da issue) e a descrição,
  com o link para o card.
- **Estimativa de volta no card:** salvar a estimativa na mesa grava o número
  no campo do projeto (por exemplo *Estimate*).
- **Token guardado com cuidado:** fica cifrado no seu computador, e só o seu
  Vcall usa. Por isso funciona só no aplicativo de mesa.

Mais detalhes em [Jogos de equipe](Jogos-de-equipe#histórias-do-github-projects).
