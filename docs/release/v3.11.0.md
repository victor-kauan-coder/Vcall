**Vcall 3.11.0**: 13 jogos novos para se divertir na chamada, reações e sinais novos, e o AppImage voltando a abrir no Linux com Wayland.

## Linux: o AppImage abre no Wayland (Fedora, Ubuntu GNOME, KDE)

Antes, numa sessão Wayland o app se fechava para se reabrir pelo XWayland. No AppImage, fechar desmonta a pasta do app (`/tmp/.mount_*`), e a cópia reaberta caía em **"Cannot mount AppImage"**: aberto pelo menu, o Vcall não subia.

Agora o próprio processo vira o novo, já com `--ozone-platform=x11`, sem sair: a pasta continua montada e a janela abre na primeira vez. Não precisa mais editar o `.desktop` à mão. Quem tinha posto `--ozone-platform=x11` no `.desktop` pode deixar: continua funcionando.

## Menu de jogos

O botão **Jogos** (atalho **K**) abre um menu com tudo, em prateleiras:

| Festa | Tabuleiro e palavras | Sorteios | Equipe ágil |
|---|---|---|---|
| Desenha e Adivinha | Jogo da velha (com computador) | Roleta com os nomes da chamada | Planning Poker |
| Stop! (adedonha) | Lig 4 (com computador) | Dados | Retrospectiva |
| Quiz | Forca | Cara ou coroa | Daily |
| Mímica (câmera em destaque) | Jogo da memória | | |
| Quem sou eu? | | | |
| Roda de perguntas | | | |
| Duas verdades e uma mentira | | | |
| Palavras-código (dois times) | | | |

Escolher um jogo avisa a chamada, com **Participar**. Como funciona cada um: [Jogos](https://github.com/victor-kauan-coder/Vcall/wiki/Jogos).

- **O que é segredo não viaja antes da hora.** A palavra do Desenha e Adivinha nunca sai do computador de quem desenha (os outros conferem o palpite por uma impressão digital), e as respostas do Stop, os votos da Roda e a mentira das Duas verdades só são publicados na revelação.
- **Sem servidor novo.** Tudo vai pelo canal direto da chamada, como o Planning Poker.
- **Funciona no celular**, em uma coluna.

## Reações e sinais

- **18 reações**, com **combo** (clique várias vezes: x2, x3...) que aparece igual para todos, e **chuva** quando três pessoas mandam a mesma.
- **Sinais que ficam no seu quadrinho**: Sim, Não, Mais devagar, Mais rápido, Pode repetir?, Não estou ouvindo e Já volto. Sim e Não viram um placar no alto da chamada; "Não estou ouvindo" avisa todo mundo; "Já volto" esmaece o seu quadrinho.
- Atalho **R** abre o menu; com ele aberto, **1 a 9** reagem direto.

Detalhes: [Reações e sinais](https://github.com/victor-kauan-coder/Vcall/wiki/Reacoes-e-sinais).

## Interface

- Jogos e sinais usam os ícones do próprio app, no degradê da marca. As reações continuam como emoji: é o que se manda.
- A chamada não desliza mais para o lado quando uma dica de botão passa da borda.

## Atualização

No computador, quem está na 3.7.1 ou mais nova no Windows ou no AppImage recebe sozinho. No `.deb` e no `.rpm`, *Configurações › Atualizações › Reiniciar e atualizar*. Todos na chamada precisam da 3.11 para jogar os jogos novos.
